# M17-PRO-handheld-console-
Technical notes and experiments on the M17 handheld console based on RK3126C, covering hardware analysis, thermal behavior, and system modification research.


🇧🇷 README – Português (Brasil)
M17 Deep Mod Project

Este projeto é experimental e educacional, focado em estudar profundamente o console portátil M17 (placa W12-V02) e explorar seus limites de hardware e software.

Objetivo

Estudar o boot, armazenamento interno e sistema Linux (EmuELEC)

Testar modificações de hardware (memória, refrigeração, controles)

Explorar comunicação externa (UART, Wi-Fi/Bluetooth via ESP32)

Criar documentação técnica inédita sobre o M17

Modificações planejadas

ESP32 (Wi-Fi + Bluetooth)

Sistema de refrigeração ativa (ventoinha + dissipação)

Estudo de memória interna vs SD

Custom firmware / CFW

Possível troca de analógicos (drift)

Modificações físicas (carcaça custom)

Aviso / Riscos

⚠️ RISCO REAL DE DANO PERMANENTE
Solda, firmware e modificações físicas podem:

Brickar o console

Superaquecer componentes

Tornar o dispositivo inutilizável

NÃO RECOMENDADO para iniciantes. Faça por sua conta e risco.

Status

Projeto em fase de estudo, repositório privado, sem releases.

🇺🇸 README – English
M17 Deep Mod Project

This is an experimental and educational project focused on deep research of the M17 handheld console (W12-V02 board) and pushing its hardware/software limits.

Goals

Study boot process, internal storage and Linux/EmuELEC

Hardware mods (memory, cooling, controls)

External communication (UART, ESP32 Wi-Fi/Bluetooth)

Create original technical documentation for the M17

Planned Modifications

ESP32 (Wi-Fi + Bluetooth)

Active cooling system

Internal storage research

Custom firmware (CFW)

Analog stick replacement (drift fix)

Physical mods / custom shell

Warning / Risks

⚠️ HIGH RISK PROJECT
Soldering and firmware mods may:

Brick the device

Cause overheating

Permanently damage hardware

Not recommended for beginners. Proceed at your own risk.

Status

Early research stage, private repository, no releases.
